# PARALLEL — VANTA R1

Cinematic scroll-driven automotive experience built with React, React Three Fiber, Three.js, GSAP, Framer Motion and Lenis.

## 3D asset

The current concept-car GLB is loaded from the Khronos glTF sample asset hosted in the `studio-public-demos/car-concept-3d-dashboard` repository. The original model is by Unity Fan and is public-domain/CC0; the optimized Khronos conversion is distributed under CC BY 4.0 and attribution is retained here.

Source: https://github.com/studio-public-demos/car-concept-3d-dashboard

The VANTA R1 presentation layer, animation system and website code are original to this project.
